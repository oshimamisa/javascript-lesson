💬 変数とテンプレートリテラル

let nickname = 'Oshima Misa';
console.log(`私の名前は${nickname}です。`);
2

📦 配列とオブジェクト（連想配列）

完了

配列（出席番号のロッカー []）と、オブジェクト（ラベル付き引き出し {}）の違いを理解しました。

配列 (ロッカー) let list = ['J', 'P'];
list[0]; //➔ 'J'
オブジェクト (引き出し) let user = { name: 'John' };
user.name; //➔ 'John'
3

🔄 ループ処理と平均値の計算

完了

大量のデータを全自動で計算する仕組みを作りました。for...of文や従来のfor文、そして自動で長さを数える .length を使って平均年齢を導き出せるようになりました。

let total = 0;
for (let i = 0; i < playerList.length; i++) {
  total += playerList[i].age;
}
console.log(total / playerList.length);
4

⚙️ 関数・引数・返り値 (return)

完了

処理を一つのパッケージとして定義し、後から好きな時に () のトリガーで起動させる仕組み。引数（パラメータ）を受け取り、return を使って結果を外側に投げる（戻す）設計をマスターしました。

function remainder(x, y) {
  return x % y;
}
let result = remainder(5, 3);
