📦 配列 vs 連想配列（オブジェクト）

JavaScriptの超重要データ構造を、見て触って完全マスター！

🎒

配列 (Array)

イメージ：出席番号付きのロッカー

同じ種類のデータを順番（出席番号）に並べて管理します。 中身を呼び出すときは、[0] や [1] のように自動で決まる「インデックス番号（添え字）」を使います。

let list = ['赤', '青', '黄'];
console.log(list[0]); // ➔ '赤'
🗂️

連想配列 (オブジェクト)

イメージ：ラベルが貼られた引き出し

データの順番は気にせず、自分で決めた「ラベル名（キー）」を使って管理します。 中身を呼び出すときは、.name のように指定したキーを使います。

let user = { name: 'John', age: 26 };
console.log(user.name); // ➔ 'John'

🎮 体感シミュレーター：ボタンを押してアクセスしてみよう！

配列：colors の中身

番号（ロッカー番号）を使って中身を取り出します。

index [0] 🍎 りんご
index [1] 🍌 バナナ
index [2] 🍇 ぶどう

連想配列：user の中身

キー（引き出しのラベル）を使って中身を取り出します。

key: name 'John' 名前
key: age 26 年齢
key: blood 'A' 血液型

> ボタンを押すとここに結果が表示されます。

➕ 途中で新しいデータを追加したいときは？

配列の場合（末尾に追加）

push() という命令を使い、新しいロッカーを自動でお尻に作ります。

colors.push('🍓');
// colors[3] に '🍓' が入る

連想配列の場合（自由に追加）

.新しいキー = バリュー の形で、好きなラベル名（キー）の引き出しを直接作ります。

user.birthday = '1999-06-22';
// userにbirthdayキーが新しく作られる

💡 「出席番号順のロッカー」なら普通の配列！ 「名前付きラベルの引き出し」なら連想配列（オブジェクト）！
